# 🎨 Módulo Frontend Mobile — Sportfy

**Responsáveis Técnicos**: Sábio e Gabriel[cite: 5]  
**Tecnologias**: React Native / Flutter, Axios, Context API, Expo[cite: 3, 5]

---

## 🎯 Objetivo do Módulo

Prover uma experiência de usuário (UX/UI) fluida, intuitiva e responsiva para o aplicativo mobile Sportfy, consumindo as APIs REST para gerenciamento de perfil e partidas esportivas[cite: 3, 5].

---

## 📱 Telas Implementadas

* **Home / Splash Screen**: Apresentação inicial da marca e atalhos rápidos[cite: 3, 5].
* **Login & Criar Conta**: Formulários interativos para autenticação e cadastro de novos atletas[cite: 3, 5].
* **Ver Eventos**: Feed em cards exibindo fotos, locais, modalidades e número de participantes[cite: 3, 5].
* **Criar Evento**: Formulário completo para criação de partidas com upload de imagem e escolha de esporte[cite: 3, 5].
* **Conta / Perfil**: Exibição da avaliação (estrelas), biografia, localização e esportes favoritos do usuário[cite: 3, 5].

```bash
# 1. Acesse o diretório do frontend
