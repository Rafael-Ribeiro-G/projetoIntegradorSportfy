# 🤖 Módulo Inteligência Artificial & Chatbot — Sportfy

**Responsável Técnico**: Guilherme[cite: 5]  
**Tecnologias**: Python, NLP (Processamento de Linguagem Natural), Dialogflow / Rasa, Scikit-Learn[cite: 3, 5]

---

## 🎯 Objetivo do Módulo

Incrementar a experiência do usuário através de um assistente virtual interativo para suporte dentro do aplicativo e de um algoritmo inteligente focado na recomendação personalizada de partidas esportivas[cite: 3, 5].

---

## 💡 Funcionalidades

* **Chatbot de Suporte**: Assistente virtual capaz de tirar dúvidas dos usuários sobre o uso do app, regras, criação de eventos e redefinição de acesso[cite: 3, 5].
* **Algoritmo de Recomendação**: Sistema de sugestão que analisa a localização, histórico de partidas e esportes favoritos do usuário para priorizar os eventos mais relevantes no feed[cite: 3, 5].
